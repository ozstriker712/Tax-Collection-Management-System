# Tax-Collection-Management-System
 A complete tax collection management system developed with C# (.NET) using Entity Framework 6, DevExpress, and a local Microsoft Access database.
The program is designed to manage and track tax collection operations for multiple shops and services efficiently.

It includes full database management (CRUD) operations — insert, update, delete — as well as user permissions, data tracking, and advanced search features.
Users can also save and back up the database, export data to Excel, and view real-time statistics via an intuitive dashboard and summary tables.

Features:

Developed with C# .NET, Entity Framework 6, and DevExpress.

Uses local Access database.

Full CRUD: insert, update, delete, and print operations.

User permission system to control access levels.

Advanced search and filtering.

Tracking and logging of all operations.

Database backup and data export to Excel.

Statistics dashboard and tables for quick insights.

Clean, responsive, and professional interface.

اسم المشروع: نظام إدارة وتحصيل العمليات الجبائية

الوصف:
نظام متكامل لإدارة وتحصيل العمليات الجبائية الخاصة بعدة محلات وخدمات،
تم تطويره بلغة C# .NET باستخدام Entity Framework 6 وواجهة احترافية من DevExpress مع قاعدة بيانات محلية Access.

يوفر النظام إدارة كاملة للبيانات (إدخال، تعديل، حذف)، بالإضافة إلى نظام صلاحيات للمستخدمين،
و تتبع جميع العمليات، و بحث بسيط ومتقدم. كما يتيح حفظ قاعدة البيانات، تصدير القوائم إلى Excel،
وعرض لوحة إحصائيات تفاعلية وجداول تحليلية لسهولة المتابعة والإدارة.

الميزات:

مطور بـ C# .NET و Entity Framework 6 و DevExpress.

قاعدة بيانات محلية Access.

إدخال، تعديل، حذف، وطباعة البيانات بسهولة.

نظام صلاحيات للمستخدمين للتحكم في الوصول.

بحث متقدم وتتبع لجميع العمليات.

نسخ احتياطي للبيانات وتصدير إلى Excel.

لوحة إحصائيات وجداول تحليلية.

واجهة أنيقة وسهلة الاستخدام.
